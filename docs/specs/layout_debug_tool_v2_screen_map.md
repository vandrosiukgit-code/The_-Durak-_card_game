## Правила

1. Shell-интерфейс строится на `pygame_gui`.

2. Стиль shell-интерфейса: Windows 95/98.

3. Игровая стилистика допускается только внутри `PREVIEW AREA`.

4. `PREVIEW AREA`:
   - game canvas `1600 x 900`;
   - aspect ratio `16:9`;
   - hover подсвечивает объект;
   - ЛКМ выбирает объект;
   - drag/resize мышью запрещены.

5. `ПАНЕЛЬ КОНТЕКСТА` и `НАВИГАТОР ОБЪЕКТОВ` не смешиваются:
   - панель контекста решает, какой экран открыт и какие объекты доступны;
   - навигатор показывает путь к выбранному объекту.

6. Основная рабочая область строится слева направо:
   - `НАВИГАТОР ОБЪЕКТОВ`;
   - `ИНСПЕКТОР`;
   - `PREVIEW AREA`.

7. Всё место ниже основной рабочей области занимает `TO DO` и `СТРОКА СОСТОЯНИЯ`.

8. Управление объектом входит в `ИНСПЕКТОР`, чтобы нижняя область оставалась для `TO DO`.

9. Инспектор показывает только свойства выбранного объекта по разрешённой property-схеме.

10. `TO DO` является навигацией по задачам, а не просто текстовым полем.

11. `Copy task` копирует структурированный текст для чата, не JSON.


## Версия v2.1

Зафиксирован стабильный shell-каркас на `pygame_gui` в стиле Windows 95/98.

Состав v2.1:
- верхняя `ПАНЕЛЬ КОНТЕКСТА`;
- рабочая область слева направо: `НАВИГАТОР ОБЪЕКТОВ`, `ИНСПЕКТОР`, `PREVIEW AREA`;
- нижняя область `TO DO`;
- `СТРОКА СОСТОЯНИЯ`;
- вдавленные Win95/98-контуры функциональных групп инспектора;
- технический рефакторинг геометрии shell в именованные зоны.
