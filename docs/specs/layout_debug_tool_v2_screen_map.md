## Правила

1. Shell-интерфейс строится на `pygame_gui`.

2. Стиль shell-интерфейса: Windows 95/98.

3. Игровая стилистика допускается только внутри `PREVIEW AREA`.

4. `PREVIEW AREA`:
   - game canvas `1600 x 900`;
   - aspect ratio `16:9`;
   - hover подсвечивает объект;
   - ЛКМ выбирает объект;
   - drag/resize мышью запрещены.

5. `ПАНЕЛЬ КОНТЕКСТА` и `НАВИГАТОР ОБЪЕКТОВ` не смешиваются:
   - панель контекста выбирает экран и режим отображения;
   - навигатор показывает объекты текущего экрана и выбранный путь.

6. Основная рабочая область строится слева направо:
   - `НАВИГАТОР ОБЪЕКТОВ`;
   - `ИНСПЕКТОР`;
   - `PREVIEW AREA`.

7. Всё место ниже основной рабочей области занимает `TO DO` и `СТРОКА СОСТОЯНИЯ`.

8. Управление объектом входит в `ИНСПЕКТОР`.

9. Инспектор показывает только свойства выбранного объекта по безопасной property-схеме.

10. `TO DO` работает с `todo_text` layout-объектов.

11. `Copy` в `TO DO` копирует структурированный текст для чата, не JSON.

## Текущие ограничения

- Кнопка `Edit` пока оставлена как будущая возможность.
- Навигатор объектов пока рабочий список/дерево в текстовом виде, не финальный полноценный tree-компонент.
- Поле создания задачи работает, но UX фокуса и курсора требует будущей полировки.
