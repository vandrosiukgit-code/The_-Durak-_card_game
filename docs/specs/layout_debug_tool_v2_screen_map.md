## Правила

1. Shell-интерфейс строится на `pygame_gui`.

2. Стиль shell-интерфейса: Windows 95/98.

3. Игровая стилистика допускается только внутри `PREVIEW AREA`.

4. `PREVIEW AREA`:
   - game canvas `1600 x 900`;
   - aspect ratio `16:9`;
   - hover подсвечивает объект;
   - ЛКМ выбирает объект;
   - drag/resize мышью запрещены.

5. `ПАНЕЛЬ КОНТЕКСТА` и `НАВИГАТОР ОБЪЕКТОВ` не смешиваются:
   - панель контекста решает, какой экран открыт и какие объекты доступны;
   - навигатор показывает путь к выбранному объекту.

6. Основная рабочая область строится слева направо:
   - `НАВИГАТОР ОБЪЕКТОВ`;
   - `ИНСПЕКТОР`;
   - `PREVIEW AREA`.

7. Всё место ниже основной рабочей области занимает `TO DO` и `СТРОКА СОСТОЯНИЯ`.

8. Управление объектом входит в `ИНСПЕКТОР`, чтобы нижняя область оставалась для `TO DO`.

9. Инспектор показывает только свойства выбранного объекта по разрешённой property-схеме.

10. `TO DO` является навигацией по задачам, а не просто текстовым полем.

11. `Copy task` копирует структурированный текст для чата, не JSON.


## Текущая правка после v2.1

- Навигатор использует pygame_gui scrollbars: вертикальный и нижний горизонтальный.
- В списке созданных задач добавлен только нижний pygame_gui scrollbar; вертикальный остаётся штатным у списка.

- Такой же Win95-scrollbar добавлен к списку созданных задач в `TO DO`.

- В навигатор объектов добавлены вертикальный и нижний горизонтальный ползунки.

- В инспекторе Object/Type увеличены и выровнены ближе к левому краю.
- Группы инспектора разнесены по вертикали, зона нижних кнопок уменьшена.

- Список задач уменьшен, `ВЫБРАННАЯ ЗАДАЧА` расширена примерно до пропорции 1:1.3.

- `Object` убран из блока создания новой задачи, поле описания увеличено по высоте.

- В `СОЗДАТЬ НОВУЮ ЗАДАЧУ` `Object` стал надписью, `Type` убран.
- Основная площадь блока отдана полю описания новой задачи, справа расположены кнопки `Add task` и `Clean`.

- После рефакторинга серого пространства в `ПРОСМОТР СОЗДАННЫХ ЗАДАЧ` стало меньше, белые поля увеличены.
- `ВЫБРАННАЯ ЗАДАЧА` стала главным полем блока просмотра и получила больше площади.

- `Object:` убран из просмотрщика выбранной задачи в `ПРОСМОТР СОЗДАННЫХ ЗАДАЧ`.
- Белые поля списка задач и выбранной задачи выровнены по верхнему и нижнему краю.

- В `ПРОСМОТР СОЗДАННЫХ ЗАДАЧ` добавлен просмотрщик выбранной задачи книжной ориентации, равный по высоте полю списка задач.
- Внизу блока просмотра оставлены только кнопки `Edit` и `Copy`.

- TO DO разделён на два логических блока: просмотр ранее созданных задач и создание новой задачи.

- TO DO уменьшен по высоте примерно на 30%.
- Высота НАВИГАТОРА ОБЪЕКТОВ, ИНСПЕКТОРА и PREVIEW AREA увеличена.

- Навигатор объектов сужен примерно на 20%.
- Освободившееся место отдано preview area.
- Sunken-группы инспектора увеличены по высоте, чтобы поля GEOMETRY, LAYOUT DELTAS и VISUAL не конфликтовали с рамками.
- Фильтр `TODO` убран из панели контекста.

## Версия v2.1

Зафиксирован стабильный shell-каркас на `pygame_gui` в стиле Windows 95/98.

Состав v2.1:
- верхняя `ПАНЕЛЬ КОНТЕКСТА`;
- рабочая область слева направо: `НАВИГАТОР ОБЪЕКТОВ`, `ИНСПЕКТОР`, `PREVIEW AREA`;
- нижняя область `TO DO`;
- `СТРОКА СОСТОЯНИЯ`;
- вдавленные Win95/98-контуры функциональных групп инспектора;
- технический рефакторинг геометрии shell в именованные зоны.
