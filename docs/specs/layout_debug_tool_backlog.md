## Главный принцип

Shell-интерфейс утилиты строится на `pygame_gui` в стиле Windows 95/98.

Ручная pygame-отрисовка допускается только внутри `PREVIEW AREA`, потому что там имитируется игровой экран. Shell-элементы, панели, кнопки, поля, списки и scrollbars должны быть `pygame_gui`-элементами или временно отсутствовать.

## Текущая рабочая точка

Файл shell-прототипа:
- `tools/layout_debug_tool_v2_shell.py`

Тема:
- `ui_theme/layout_debug_tool_win95.json`

Состояние:
- shell-прототип существует отдельно от старой утилиты;
- старый файл `tools/layout_debug_tool.py` не трогаем;
- интерфейс визуально отделён от игры стилем Windows 95/98;
- ручные shell-scrollbars и ручные shell-frame overlays убраны;
- ручная отрисовка осталась только для preview-заглушки.

2. В `ПАНЕЛЬ КОНТЕКСТА` есть:

4. Основная рабочая область слева направо:
   - `НАВИГАТОР ОБЪЕКТОВ`;

5. Нижняя область:
   - `TO DO`;

   - сохраняет canvas `1600 x 900` и aspect ratio `16:9`;

   - drag/resize мышью запрещены;
   - остальная настройка объекта идёт через инспектор.

## Зафиксированная рабочая версия shell

Состояние зафиксировано в кодовой ветке `codex/new-feature` коммитом `822df39 Finalize layout debug shell scaffold`.
