# ADR: отдельная ветка архитектурного backlog для Layout Debug Tool v2

Дата: 2026-05-17.

Статус: принято.

## Контекст

`Layout Debug Tool v2` достиг первой рабочей живой версии. Пользователь подтвердил, что рабочий backlog v2 можно считать закрытым.

При этом текущий код утилиты вырос из shell-прототипа в большой файл, который уже содержит:
- UI;
- состояние;
- загрузку;
- сохранение;
- preview-геометрию;
- TODO;
- clipboard;
- обработку событий.

Дальнейшее развитие без архитектурного плана приведёт к росту хрупкости и увеличению количества временных решений.

## Решение

Создать отдельную ветку `architecture`.

Назначение ветки:
- хранить только документацию по архитектуре и качеству кода;
- формулировать строгие принципы;
- фиксировать аудит текущего состояния;
- вести backlog рефакторинга;
- не смешивать архитектурные решения с кодовыми изменениями.

## Состав первой версии ветки

```text
docs/architecture/code_quality_principles.md
docs/architecture/layout_debug_tool_v2_code_audit.md
docs/tasks/architecture/layout_debug_tool_v2_architecture_backlog.md
docs/decisions/adr_layout_debug_tool_v2_architecture_branch.md
```

## Правила

1. Ветка `architecture` содержит документацию, а не код.

2. Код меняется в рабочих кодовых ветках только после согласования этапа.

3. Архитектурный backlog не является разрешением на автоматический рефакторинг.

4. Каждый рефакторинг должен быть маленьким, проверяемым и не ломать подтверждённое поведение v2.

5. Пользователь не обязан разбираться в архитектуре кода. Ответственность за техническую формулировку принципов, аудит и порядок работ берёт Codex.

## Последствия

Плюсы:
- появляется строгая система координат;
- рефакторинг становится управляемым;
- легче отличать нужную архитектурную работу от вкусовой переделки;
- снижается риск сломать уже рабочую утилиту.

Минусы:
- появляется ещё одна ветка документации;
- перед кодовыми изменениями нужно поддерживать связь между backlog и реализацией.

## Итог

Ветка `architecture` нужна как технический фундамент для дальнейшего рефакторинга Layout Debug Tool v2.
