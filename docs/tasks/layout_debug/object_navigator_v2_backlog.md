# Layout Debug Tool v2: Object Navigator v2 Backlog

## Статус

Черновик принят для дальнейшей реализации.

## Концепт

Навигатор объектов становится интерактивным деревом выбора объектов текущего экрана.

Главная цель навигатора: дать надежный доступ к объектам, которые невозможно или неудобно выбрать ЛКМ в `PREVIEW AREA` из-за перекрытий, вложенности или малого размера.

Навигатор не является просто списком. Это рабочая карта структуры экрана.

## Базовые правила

- Дерево всегда показывает полный список объектов текущего экрана.
- Collapse/expand не нужен.
- Каждая строка дерева соответствует одному `object_id`.
- `hover` и `selected` являются разными состояниями.
- `hover` временный и существует только пока курсор находится над объектом.
- `selected` фиксируется кликом и сохраняется до следующего выбора.
- Инспектор работает только с `selected`.
- Объект можно выбрать как через `PREVIEW AREA`, так и через Навигатор.

## Backlog

### 1. Заменить визуальное тело навигатора

- Заменить текущий `UITextBox` на `UISelectionList`.
- Список показывает дерево текущего экрана.
- Каждая строка связана с конкретным `object_id`.
- Collapse/expand не делать.

### 2. Построить явную модель дерева

- Описать parent-child структуру для экранов:
  - `game_table`;
  - `main_menu`;
  - `modal_intro`;
  - `modal_endgame`.
- Порядок строк должен соответствовать логике render-слоев.
- Геометрическую иерархию можно оставить только как fallback.

### 3. Сформировать строки дерева

- Отображать строки с отступом по уровню вложенности.
- Показывать короткое имя объекта.
- При необходимости показывать тип объекта.
- На первом этапе selected/hover можно помечать текстовым маркером.

### 4. Синхронизация PREVIEW AREA -> Navigator

- Движение мыши по `PREVIEW AREA` обновляет временный `hover`.
- Строка hover-объекта подсвечивается или помечается.
- Уход курсора из `PREVIEW AREA` сбрасывает hover.
- Клик в `PREVIEW AREA` выбирает объект и обновляет selected-строку.

### 5. Синхронизация Navigator -> PREVIEW AREA

- Клик по строке дерева выбирает объект.
- Выбранный объект подсвечивается в `PREVIEW AREA` поверх остальных.
- Инспектор обновляется.
- TO DO view синхронизируется с выбранным объектом.

### 6. Развести состояния hover и selected

- `hover` не меняет инспектор.
- `hover` не меняет `selected`.
- `hover` исчезает при уходе курсора.
- `selected` управляет инспектором и редактированием.

### 7. Проверить перекрытые объекты

- Выбрать через дерево объект, недоступный ЛКМ в `PREVIEW AREA`.
- Проверить, что он явно подсвечивается.
- Проверить, что кнопки движения и изменения размера применяются именно к нему.
- Проверить `Apply`, `Reset session`, `Cancel`, `Dismiss`.
