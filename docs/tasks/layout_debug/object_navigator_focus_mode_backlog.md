# Layout Debug Tool v2: Object Navigator Focus Mode Backlog

## Статус

Черновик принят для реализации после стабилизации двусторонней синхронизации `PREVIEW AREA` и `НАВИГАТОРА ОБЪЕКТОВ`.

## Концепт

Фокусный режим навигатора нужен, чтобы быстро добираться до перекрытых, маленьких или глубоко вложенных объектов без скрытия слоев игры.

Вместо управления видимостью объектов навигатор временно перестраивает дерево вокруг выбранного объекта:

- показывает родительскую цепочку от верхнего уровня до выбранного объекта;
- показывает выбранный объект;
- показывает всех потомков выбранного объекта;
- убирает из навигатора все соседние ветки, которые сейчас мешают ориентироваться.

Игровая отрисовка в `PREVIEW AREA` при этом не меняется. Меняется только способ навигации по дереву.

## Базовые правила

- ЛКМ по строке дерева выбирает объект.
- Hover по строке дерева подсвечивает объект в `PREVIEW AREA`.
- ПКМ по строке дерева включает фокусный режим для этой строки.
- В фокусном режиме `selected` и `hover` работают так же, как в полном дереве.
- Фокусный режим не меняет layout-данные и не создает dirty-состояние.
- Фокусный режим сбрасывается при смене экрана.
- Выход из фокусного режима: `Esc` или ПКМ по пустому месту навигатора.
- Collapse/expand не нужен.
- Ручной отрисовки shell-элементов не добавлять: тело навигатора остается на `pygame_gui.UISelectionList`.

## Backlog

### 1. Ввести явную модель дерева

- Создать структуру узла дерева для навигатора.
- Узел должен хранить:
  - `object_id`;
  - уровень вложенности;
  - родителя;
  - список детей;
  - ссылку на `LayoutObject` или безопасный идентификатор для поиска.
- Построение дерева должно опираться на текущий явный порядок render-слоев.
- Fallback-объекты без известного места в дереве показывать отдельными корневыми узлами.

### 2. Научиться искать путь к объекту

- Для любого `object_id` находить цепочку:
  - корневой объект;
  - промежуточные родители;
  - выбранный объект.
- Если объект не найден, возвращать пустой результат без падения.
- Покрыть тестом путь для `game_table`.

### 3. Научиться собирать потомков объекта

- Для любого `object_id` находить всех потомков ниже по дереву.
- Потомки должны идти в визуальном порядке дерева.
- Если у объекта нет детей, в фокусном режиме показывать только родительскую цепочку и сам объект.
- Покрыть тестом ветку с детьми и объект без детей.

### 4. Сформировать список строк фокусного режима

- В полном режиме навигатор показывает весь экран.
- В фокусном режиме навигатор показывает:
  - строку-индикатор режима;
  - родительскую цепочку;
  - выбранный фокусный объект;
  - потомков фокусного объекта.
- Строка-индикатор не должна быть выбираемым layout-объектом.
- Mapping `label -> object_id` должен работать только для строк объектов.

### 5. Подключить ПКМ по строке навигатора

- ПКМ по строке объекта включает фокусный режим для этого объекта.
- Объект под ПКМ становится `selected`.
- `PREVIEW AREA`, инспектор, TO DO и статус обновляются через общий механизм выбора.
- Hover остается временным и не конфликтует с selected.

### 6. Подключить выход из фокусного режима

- `Esc` возвращает полный список текущего экрана.
- ПКМ по пустому месту навигатора возвращает полный список текущего экрана.
- При выходе из фокуса selected не сбрасывается.
- При смене экрана фокусный режим сбрасывается автоматически.

### 7. Обновить строку состояния

- В статусе показывать, включен ли фокусный режим.
- Пример: `focus: player_left_panel` или `focus: -`.
- Статус не должен перегружать экран, но должен помогать понять, почему дерево стало короче.

### 8. Проверить пользовательский сценарий

- Выбрать объект в полном дереве.
- ПКМ включить фокус.
- Пройти hover по родительской цепочке и потомкам.
- ЛКМ выбрать потомка.
- Убедиться, что объект подсвечен в `PREVIEW AREA`.
- Убедиться, что инспектор показывает выбранный объект.
- Нажать `Esc` и вернуться к полному дереву без потери selected.

### 9. Обновить документацию

- Обновить основной backlog навигатора.
- Обновить спецификацию `layout_debug_tool_v2.md`, если поведение будет принято пользователем.
- Обновить карту экрана только если появится видимый индикатор фокусного режима.

## Порядок реализации

1. Сначала сделать модель дерева без изменения поведения.
2. Затем добавить генерацию полного списка через модель дерева.
3. Затем добавить генерацию фокусного списка.
4. Затем подключить ПКМ.
5. Затем подключить выход из режима.
6. После каждого шага запускать утилиту и давать пользователю проверить поведение.

## Критерий готовности

Этап считается готовым, когда пользователь может выбрать перекрытый объект через навигатор так:

1. Найти близкий родительский объект.
2. ПКМ открыть фокусную ветку.
3. Навести курсор на нужного потомка и увидеть подсветку в `PREVIEW AREA`.
4. ЛКМ выбрать потомка.
5. Редактировать объект в инспекторе без необходимости скрывать игровые слои.
