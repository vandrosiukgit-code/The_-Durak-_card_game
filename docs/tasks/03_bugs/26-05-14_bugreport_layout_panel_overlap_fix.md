# Layout panel overlap

### Место: layout_debug_tool.py

- **Статус:** Open
- **Серьезность:** Minor
- **Что происходит:** Размещение панели управления перекрывает кнопки в меню "Settings".
- **Ожидаемое поведение:** Кнопки управления должны быть в постоянном доступе.
- **Fixing**: Создать кнопки управления в отдельном компактном меню 320 х 420 пикселей. Это меню можно при помощи ПКМ двигать
по экрану освобождая доступ к редактируемым элементам
