# [Некорректный порядок анимации раздачи карт в player_bottom_panel]

- **Статус:** Open
- **Серьезность:** Minor
- **Что происходит:** Порядок анимации раздачи карт нарушен: карты сначала появляются в руке игрока, а только потом проигрывается анимация их перемещения из колоды в руку.
- **Ожидаемое поведение:** Анимация должна быть последовательной: сначала определяется место новой карты в руке, колода сдвигается, и карта плавно «прилетает» из колоды точно в отведенное ей место.
- **Как исправить:**
    1. Получить от движка список карт, которые берет игрок.
    2. Модифицировать алгоритм отображения карт в руке нижнего игрока для определения точной позиции каждой новой карты.
    3. Запустить анимацию сдвига карт в руке (освобождение места для новой карты).
    4. Запустить анимацию перемещения карты из колоды. Важно: траектория полета карты должна быть динамически привязана к целевой позиции в руке.
    *Примечание: после исправления реализовать обратную анимацию хода (карта летит из руки на стол).*
- **Контекст/Логи:** Компонент `player_bottom_panel`. Проблема проявляется при взятии карт из колоды нижним игроком.
